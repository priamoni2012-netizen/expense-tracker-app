# আর্থিক ব্যবস্থাপনা অ্যাপ্লিকেশন

এটি একটি সম্পূর্ণ আয় ও ব্যয় ট্র্যাকিং অ্যাপ্লিকেশন যা ব্রাউজারে চলে।

## বৈশিষ্ট্যসমূহ

### ১. লেনদেন ট্যাব
- **প্রতিষ্ঠানের নাম**: সম্পাদনযোগ্য প্রতিষ্ঠানের নাম
- **তারিখ পিকার**: প্রতিটি লেনদেনের জন্য তারিখ নির্বাচন করুন
- **আয় ও ব্যয়**: দুটি ধরনের লেনদেন সাপোর্ট করে
- **ক্যাটাগরী**: প্রি-ডিফাইনড এবং কাস্টম ক্যাটাগরী যোগ করুন
- **বিবরণ**: প্রতিটি লেনদেনে বিবরণ যোগ করুন
- **ক্যাটাগরী ম্যানেজমেন্ট**: ডানদিকে ক্যাটাগরী যোগ/মুছুন

### ২. ব্যালান্সিং ট্যাব
- **দৈনিক ব্যালান্স**: নির্বাচিত তারিখের জন্য আয় - ব্যয় = ব্যালান্স
- **ব্যাংক-১ এবং ব্যাংক-২**: সম্পাদনযোগ্য ব্যাংক নাম এবং ব্যালান্স
- **হাতে নগদ**: স্বয়ংক্রিয়ভাবে গণনা করা হয় (মোট - ব্যাংক)

## ব্যবহার

1. `index.html` ফাইলটি ব্রাউজারে খুলুন
2. প্রতিষ্ঠানের নাম সম্পাদনা করুন
3. লেনদেন যোগ করুন বা ক্যাটাগরী পরিচালনা করুন
4. ব্যালান্সিং ট্যাবে আপনার ব্যালান্স দেখুন

## ডেটা সংরক্ষণ

সব ডেটা ব্রাউজারের Local Storage এ সংরক্ষিত হয়। ডেটা হারিয়ে যাবে না যদি আপনি:
- ব্রাউজার ক্লোজ করেন
- কম্পিউটার রিস্টার্ট করেন

## ভাষা

অ্যাপ্লিকেশনটি সম্পূর্ণ বাংলায় তৈরি করা হয়েছে।
